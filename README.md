# Maryam Fatima — Portfolio

A full-stack portfolio site:

- **Frontend:** Next.js 14 (App Router, TypeScript, Tailwind CSS)
- **Backend:** FastAPI (Python) serving the resume data and handling the contact form

The design is styled like an ML "model card" (à la Hugging Face) — a YAML-style
metadata block in the hero, tag pills for skills, and section labels written as
`key: value` pairs — since that's genuinely the world Maryam works in
(she deploys her own projects to Hugging Face Spaces).

```
portfolio/
├── backend/          FastAPI app
│   ├── main.py        routes: GET /api/profile, POST /api/contact, GET /api/health
│   ├── data.py         all resume content lives here — edit this to update the site
│   ├── models.py       request/response schemas
│   └── requirements.txt
└── frontend/         Next.js app
    ├── app/            pages, layout, global styles
    ├── components/     Hero, About, Skills, Experience, Projects, Education, Contact, etc.
    └── lib/            types + data fetching (calls the backend, falls back to static data)
```

## 1. Run the backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

The API is now live at `http://localhost:8000`. Check `http://localhost:8000/docs`
for interactive Swagger docs (auto-generated by FastAPI).

Contact-form submissions are appended to `backend/messages.json`. Swap that logic
in `main.py` for an email send or database insert whenever you're ready.

## 2. Run the frontend

In a separate terminal:

```bash
cd frontend
npm install
cp .env.local.example .env.local   # points the frontend at http://localhost:8000
npm run dev
```

Open `http://localhost:3000`. The homepage fetches your profile from the FastAPI
backend at build/request time; if the backend isn't reachable it falls back to
the static copy in `frontend/lib/data.ts` so the site never breaks.

## 3. Edit your content

- **Resume content:** edit `backend/data.py` (and keep `frontend/lib/data.ts` in
  sync as the fallback).
- **Colors/fonts:** `frontend/tailwind.config.ts` and `frontend/app/globals.css`.
- **Sections:** each section is its own component in `frontend/components/` —
  add, remove, or reorder them in `frontend/app/page.tsx`.

## 4. Deploying

- **Frontend:** Vercel is the easiest path for Next.js — push to GitHub, import
  the repo, set `NEXT_PUBLIC_API_URL` to your deployed backend's URL.
- **Backend:** any host that runs Python works (Render, Railway, Fly.io, a VPS).
  Run with `uvicorn main:app --host 0.0.0.0 --port $PORT`, and set the
  `allow_origins` in `main.py`'s CORS middleware to your real frontend domain
  instead of `"*"` before going live.
